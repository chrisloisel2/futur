================================================================================
CONFIGURATION
================================================================================

Le fichier de configuration est : configs/train_s3.yaml

Paramètres principaux :
- start_year: 2020          # Année de début
- end_year: 2024            # Année de fin
- symbols_filter: [...]     # Symboles à charger
- lookback_window: 100      # Taille de la séquence
- batch_size: 32            # Taille des batches
- epochs: 50                # Nombre d'epochs

Pour modifier ces paramètres, éditez le fichier :
```
nano configs/train_s3.yaml
```

================================================================================
RÉSOLUTION DE PROBLÈMES
================================================================================

ERREUR : "ModuleNotFoundError: No module named 'data_pipeline'"
SOLUTION : Vous n'êtes pas dans le bon répertoire ou PYTHONPATH n'est pas défini
→ cd /Users/christopher/Desktop/futur/ai
→ Utilisez PYTHONPATH=TRAIN:$PYTHONPATH avant la commande

ERREUR : "ModuleNotFoundError: No module named 'data'"
SOLUTION : Même cause que ci-dessus

ERREUR : Credentials AWS
SOLUTION : Vérifiez vos credentials
→ aws configure
→ Ou vérifiez ~/.aws/credentials

ERREUR : Mémoire insuffisante
SOLUTION : Réduisez batch_size dans la config
→ batch_size: 16  # Au lieu de 32

Exemple 3 : Configuration personnalisée
```bash
cd /Users/christopher/Desktop/futur/ai

# Créer une config personnalisée
cat > /tmp/my_config.yaml << 'EOF'
data:
  data_source: "s3"
  s3_bucket: "qbia"
  s3_prefix: "bourse/mintrad"
  start_year: 2023
  end_year: 2024
  symbols_filter: ["BTCUSDT", "ETHUSDT"]
  local_cache_dir: "/tmp/trading_cache"
  lookback_window: 50
  batch_size: 64

model:
  params:
    d_model: 512
    n_heads: 8
    feature_dim: 52

training:
  epochs: 20
  learning_rate: 0.0001
  checkpoint_dir: "my_checkpoints"
EOF

# Lancer l'entraînement
PYTHONPATH=TRAIN:$PYTHONPATH python3 train.py \
    --config /tmp/my_config.yaml \
    --device mps

# Nettoyer
rm /tmp/my_config.yaml
```
