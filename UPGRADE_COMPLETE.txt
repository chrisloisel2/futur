================================================================================
                         📊 BACKEND API ENDPOINTS
================================================================================

S3 Data Endpoints (NOUVEAUX) :
  GET  /s3/overview              - Vue d'ensemble S3
  GET  /s3/years                 - Années disponibles
  GET  /s3/symbols/{year}        - Symboles par année
  GET  /s3/data/{symbol}/{year}  - Données OHLCV
  GET  /s3/latest/{symbol}       - Dernières données

Pipeline Endpoints (NOUVEAUX) :
  POST /pipeline/start           - Démarrer prédictions
  POST /pipeline/stop            - Arrêter pipeline
  GET  /pipeline/status          - Statut + stats
  GET  /pipeline/predictions     - Toutes prédictions
  GET  /pipeline/prediction/{symbol} - Prédiction spécifique

Documentation API :
  http://localhost:8000/docs     - Swagger UI
  http://localhost:8000/redoc    - ReDoc
